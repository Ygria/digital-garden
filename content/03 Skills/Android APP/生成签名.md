# 1. 使用 Android Studio 中的 Keystore 工具

1. 打开 Android Studio → **Build** 菜单 → **Generate Signed Bundle / APK…**

2. 选择 **APK** → 下一步

3. 点击 **Create new…**

4. 填写：

- **Key store path** → 选个位置保存，例如 `release.keystore`
	
- **Password** → 这是 `RELEASE_KEYSTORE_PASSWORD.  
	
- **Key alias** → 随便填，例如 `release`（这是 `RELEASE_KEY_ALIAS`）
	
- **Key password** → 填一样的（这是 `RELEASE_KEY_PASSWORD`）
	
1. Finish → 你就拿到一个 `release.keystore` 文件了 ✅



## 2 . 使用 base 64，对 key 的内容进行编码

`base64 < release.keystore > text.txt`

然后将内容放到 `Base64内容中`
