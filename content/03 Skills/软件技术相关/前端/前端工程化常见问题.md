#计算机/前端工程化面试

 Package. Json 文件中的 devDependencies 和 dependencies 对象有什么区别?
?
 `dependencies` 放项目 **运行时必需的依赖**。
 当你的项目在生产环境运行时，这些库必须存在。
例如：
你写一个 Vue 或 React 项目，`vue`、`react` 就应该放在 `dependencies` 里。
如果你需要 `axios` 在前端发请求，也要放在 `dependencies` 里。
安装时：
```bash
npm install <package> --save # 或者直接 npm install <package>
``` 
devDependencies:  开发/构建/测试时需要的库, 例如： `vite`、`webpack`、`eslint`、`typescript`
