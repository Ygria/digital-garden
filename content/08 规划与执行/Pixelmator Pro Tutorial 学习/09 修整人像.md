Retouch - 润饰，修饰

> [!note]
> 修饰皮肤，需要在保留原有皮肤质感细节的同时，修掉瑕疵。


1. 按住 Command + J，快速复制图层
2. 使用魔术笔，修掉明显的瑕疵
3. 使用频率分离技术来平滑皮肤

4. Low pass filter —— 低通滤波器 High pass filter 高通滤波器

低通： 修改更大的纹理和颜色，而不影响更精细、高频的纹理

按 F，创建 Effect，降低饱和度到 0

5. 局部色修： 创建颜色调整图层，增加蒙版，蒙版使用局部选择-70%调整
6. 统一高光 —— 使用笔刷绘制，重叠图层设置为 darken。按住 Alt 取色，选择高光附近的颜色。
7. 快速对比 —— 按住 Alt，切换原始图层的可见范围，可以快速查看修图前后对比。
